# MP3 → TXT 本地转写工具使用文档

## 首次使用

1. 双击项目中的 `launcher/启动.bat`，打开图形启动器。
2. 查看状态区。首次显示“依赖未就绪”或“模型未就绪”属于正常情况。
3. 点击「初始化 / 修复」。首次会下载 Python 包和 small 模型，通常有数百 MB；请保持网络可用并预留磁盘空间。
4. 初始化期间可以继续查看窗口中的进度，不要关闭窗口。程序只在准备依赖时联网，音频不会上传。
5. 看到“初始化完成”后，程序会自动启动本地服务，无需再点启动按钮。
6. 状态显示“服务在线”后，点击「打开转写页面」。

如果初始化中断，直接再次点击「初始化 / 修复」即可。已完成的有效文件会复用，未完成的临时文件不会替换旧环境。

## 日常使用

1. 双击 `launcher/启动.bat`。
2. 如果服务未在线，点击「启动 / 重启服务」。
3. 点击「打开转写页面」。
4. 在页面选择或拖入一个 `.mp3` 文件，确认文件名和大小。
5. 点击「开始转写」，等待进度完成。
6. 在文本区检查并修改文字。
7. 点击「下载 TXT」，得到 `原文件名.txt`；也可以点击「复制文本」。
8. 需要处理另一个文件时，点击「重新转写」，当前页面结果会被清空。

转写期间不要关闭启动器或本地服务。浏览器页面可以刷新查看本地服务是否仍在线，但刷新会清除当前页面展示的任务状态，因此建议等待完成后再刷新。

## 页面按钮说明

| 按钮 | 作用 |
|---|---|
| 上传区域 /「更换文件」 | 打开文件选择框；也可以把文件拖进上传区域 |
| 「开始转写」 | 创建本地转写任务，同一时刻只处理一个任务 |
| 「复制文本」 | 复制当前文本框中的全部内容 |
| 「下载 TXT」 | 按 `原文件名.txt` 下载当前文本框内容，包含手动编辑 |
| 「重新转写」 | 清空当前文件、进度和结果，回到上传状态 |

## 高级配置与模型切换

日常不需要修改配置。确有需要时，点击启动器「高级配置」，在窗口中编辑本机私有配置，再点击「保存并应用」。程序会备份旧配置并立即生成生效配置；如果服务此前在线，会自动重启。模型、设备或依赖版本发生变化时，再按提示点击「初始化 / 修复」完成下载和验证。

可调整项包括本机依赖根、CPU/GPU、计算精度、语言和服务地址。配置文件采用 JSON 语法；请从同目录示例复制，保留引号、逗号和括号。模型名称、下载仓库、依赖版本等公共默认值位于 `config/stack.yaml`，不建议为日常使用修改。

切换模型意味着重新下载并验证模型，不需要训练，也不会改动已有 TXT。设备不满足更大模型需求时，不建议切换。

## 排错

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击后提示找不到 Python | 未安装兼容 Python，启动器无法引导 | 安装 Python 3.10 或更高版本并勾选启动器支持，再重新双击；由 uv 安装且注册到 Python 启动器的 3.12 也会被自动发现 |
| 「初始化 / 修复」失败 | 网络中断、磁盘不足或 Python 不兼容 | 查看启动器中的人话提示，释放空间或恢复网络后再次点击同一按钮 |
| 提示“首次使用需下载模型，请稍候” | 模型尚未就绪或正在首次加载 | 首次保持联网并等待；若长时间无变化，回到启动器点击「初始化 / 修复」 |
| 服务启动失败，提示地址被占用 | 配置的本地端口被其他程序使用 | 在「高级配置」中换一个服务端口，保存后重新启动 |
| 页面提示“仅支持 MP3 文件” | 文件后缀不是 `.mp3` | 先用可靠工具转为 MP3；不要只修改文件后缀 |
| 提示文件过大 | 超过配置的上传上限 | 分割或压缩音频；确有需要时在本机配置调整上限 |
| 转写失败并显示音频无法读取 | 文件损坏或实际编码不受支持 | 用播放器确认可播放，再重新编码为标准 MP3 |
| 转写速度慢 | CPU 模式、音频较长或内存不足 | 等待当前任务完成，避免同时运行大型程序；有兼容显卡时再考虑 GPU 配置 |
| 识别不准确 | 噪声、口音、重叠说话或模型能力限制 | 尽量使用清晰音频，必要时评估更大模型；不保证换模型一定改善 |
| 页面结果丢失 | 刷新了页面或点了「重新转写」 | 到 `data/output` 查找服务保存的同名 TXT；页面未提交的编辑无法自动恢复 |
| 想知道详细错误 | 启动器只显示简要原因 | 点击启动器中的日志位置，查看 `data/logs`；不需要在命令行运行内部脚本 |

## 数据位置、备份与迁移

- 服务保存的文本：`data/output`。
- 临时上传：`data/input`，正常完成后自动删除。
- 模型与运行环境：`dep_root` 指向的项目同级依赖目录。
- 私有配置：`config/stack.local.yaml`。

备份时至少复制 `data/output` 和 `config/stack.local.yaml`；仍需保留的原始音频也请自行备份。换电脑可直接复制项目和输出文本，然后在新电脑重新初始化，通常不必复制旧运行环境。网络不便时，可同时迁移整个依赖目录，但必须确认操作系统和架构兼容。

卸载时关闭启动器，删除项目目录与 `dep_root` 指向的依赖目录即可。浏览器已下载的 TXT 需要单独删除。操作前备份仍需保留的文本和音频。
