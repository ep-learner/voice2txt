# 声转文 · MP3 → TXT

双击启动器，在浏览器里把 MP3 转成本地纯文本。结果可编辑、复制，并按 `原文件名.txt` 下载；不包含时间戳，音频不上传云端。

## 首次使用

1. 使用 Windows，准备 Python 3.10 或更高版本，并预留至少 2.5 GB 磁盘空间。
2. 双击 [启动.bat](launcher/启动.bat)。
3. 点击「初始化 / 修复」。首次会联网安装 Python 依赖并下载 small 模型，通常有数百 MB。
4. 初始化成功后会自动启动服务；点击「打开转写页面」。

运行环境和模型默认放在项目同级的 `voice2txt-deps`，不进入项目仓库。已有有效文件会复用，初始化中断可再次点击同一按钮。

## 日常使用

双击 [启动.bat](launcher/启动.bat)，确认“服务在线”，点击「打开转写页面」。选择或拖入 MP3 →「开始转写」→ 检查/编辑文本 →「下载 TXT」。

- 只支持单个 `.mp3` 文件。
- 默认使用中文识别、CPU 和 int8，无 NVIDIA 显卡也能运行。
- 服务生成的文本保存在 `data/output`；浏览器下载包含当前文本框中的编辑内容。
- 关闭启动器会停止由它启动的本地服务。

更多操作和排错见 [使用文档](docs/03-使用文档.md)。

## 配置与升级

日常不需要修改配置。本机设备或路径需要调整时，点击启动器「高级配置」，再点击「保存并应用」。

- [initProject](initProject.md)：给 Agent 的新机器初始化 SOP。
- [levelup](levelup.md)：给 Agent 的升级、验证与回滚 SOP。
- [常见问题](qamd.md)：下载、迁移、模型与故障的高价值问答。

启动器的「检查升级」只读取公开版本，不会自动覆盖可用环境。实际升级按 `levelup.md` 在独立目录验证后再切换。
